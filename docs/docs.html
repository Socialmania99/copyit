Getting started

Copyit is a private clipboard history for Chrome. It keeps text, links, code, rich text, images and videos you save, on your device only.

  1. Install Copyit from the Chrome Web Store, or load the extension folder from GitHub with chrome://extensions → Developer mode → Load unpacked.
  2. Pin it: click the puzzle icon in Chrome and pin Copyit.
  3. Click the Copyit icon (or press Ctrl+Shift+Y, Cmd+Shift+Y on Mac).

Saving clips

  • Save clipboard button: reads what you last copied and saves it.
  • Ctrl+V inside the Copyit popup saves what you paste.
  • + button: type or paste text yourself.
  • Right-click anything on a web page: Save to Copyit. Right-click an image or video for the media options.
  • Drop files onto the dashboard: images, videos, text, .json, .csv.

Copyit never watches your clipboard in the background. It reads it only when you ask.

The popup list

Every clip is one compact row. The icons on each row, left to right:

  • QR: scan to open the clip on your phone.
  • Star and Pin: keep important clips on top.
  • Eye (Preview): opens the preview window in the dashboard.
  • Pencil: edit text or tags.
  • Three dots: copy as plain text, with formatting, Markdown and more.
  • Bin: delete (click twice to confirm).
  • Copy button: copies the clip.

Press Alt+1 to Alt+9 to copy one of your first nine clips. Hover the i icon in the popup for this tip.

Filters

Use All, Pinned and Starred, the search box (supports #tags and types) and the type chips. Scroll the chips with your mouse wheel, or click the arrow beside them to show every type and click again to fold them back.

Folders and tags

Press New folder to create a folder. Move a clip with the three dots menu. Add tags in Edit, separated by commas, and click a tag to filter.

Preview and edit window

Press the eye icon on a clip. The dashboard opens and shows the clip in a window.

  • Text, links, code, rich text: press Edit, change it, then Save changes or Discard. Find (Ctrl+F) highlights words while editing.
  • Pictures, videos, vectors, media links, websites: shown inside the window. Buttons: Open in new tab, Download, Copy.
  • Resize by dragging the corner. Move by holding the right mouse button on the window and dragging. Use the rotate button to switch between mobile (tall) and desktop (wide). Use Minimize and Maximize next to it.
  • Website links need Allow website previews once. Sites that refuse to be framed or need a sign-in (for example Google Docs) still need Open in new tab.

Tools (bottom left of the popup)

Press Tools. Each tool has a toggle and is off by default. The first time you switch one on, Chrome asks once to let Copyit work on websites. Switch all off and the permission is returned.

Click to copy

Hover text on any page and click once to copy it. Choose Paragraph, Sentence or Selection. Optionally save each copy to your list. Links, buttons and text fields are left alone. Hold Alt to click normally.

Copy text from images & videos (OCR)

Hover a picture or a paused video, press Copy text. The reader is built into Copyit and works offline. Nothing is uploaded. Emoji and decorative symbols are not recognised.

Pop-out player (picture in picture)

This works only for video and audio you saved in Copyit. Open the saved clip in the preview window and press the pop-out button at the top. A small player floats above your other windows, with play/pause, seek, mute, Minimize, Maximize and Back to Copyit. Copyit does not add any button to the videos on websites you visit. Needs Chrome 116 or newer for the full window.

Right-click on pictures and videos

  • Copy image directly (Copyit): straight to your clipboard, and the picture is also saved as an image clip in your Copyit list. If a website blocks reading the picture, Copyit copies what is visible on screen instead and tells you.
  • Copy video frame as image: the frame you are looking at. It is also saved as an image clip in your list.
  • Preview in Copyit: opens a viewer window.
  • Save image address to Copyit: saves the link.
  • Copy text from this image or video: OCR, works even with the tool switched off.

Inside Copyit, right-click a saved picture or video for Preview, Copy image and the other copy options.

Dashboard

Press the arrow icon at the top of the popup. Copyit opens one dashboard tab only; if it is already open you are taken to it. The dashboard has the same clips in a roomy layout, plus import and export.

Settings

Settings is its own full page. Press the sliders icon at the bottom right of the popup, or the gear on the dashboard. A sidebar lists the categories. The Back to Dashboard button at the top returns you. On a small window the sidebar folds into a menu button.

  • General: light, dark or auto, and a custom colour picker (wheel, brightness, swatches, hex) that recolours every Copyit page, version, support email, website, GitHub, privacy policy and Buy me a coffee.
  • Page tools: switches for Click to copy and Copy text from images & videos.
  • Privacy & security: blur sensitive clips, preview links on hover, keep sensitive clips out of backups.
  • Storage & clean-up: delete old clips, keep at most, and how much space Copyit uses.
  • Import & export: JSON, CSV, Text and Markdown backups, and import.
  • Danger zone: clear all clips (you can undo for a few seconds).
  • Support (sidebar): Contact us and Docs & Guide open the Copyit website.

Troubleshooting

  • Page tools do nothing: reload the page after switching a tool on, and check Chrome did not block website access (chrome://extensions → Copyit → Details).
  • A website will not show in Preview: use Open in new tab.
  • Copy image says it could not copy: click the page once, then try again. Chrome blocks clipboard writes when the page is not focused.
  • YouTube preview fails: check your internet. The player is a small page on socialmania99.com.
  • Lost clips: they live in this Chrome profile only. Export a JSON backup regularly.

Still stuck? Email socialmania99@gmail.com or open an issue.
